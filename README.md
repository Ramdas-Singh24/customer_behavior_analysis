#Customer Behavior Analysis

📌 Overview  
This project explores customer purchase behavior through data analytics. It covers the full pipeline: loading raw data, cleaning and preparing it, running SQL queries, performing exploratory analysis, and building interactive dashboards in Power BI. A structured report and presentation summarize the findings.

📊 Dataset  
- Source: Customer transaction and review data  
- Size: Medium dataset with ratings, purchases, and demographics  
- Cleaning: Missing values handled, ratings filled using median groupby logic  

🛠️ Tools Used  
- Python (pandas) for data loading, cleaning, and EDA  
- PostgreSQL for structured queries and storage  
- Excel for quick checks and tabular analysis  
- Power BI for interactive dashboards  
- Gamma for professional PPT creation  

🔎 Steps  
1. Load dataset into Python using pandas  
2. Perform EDA: summary stats, groupby, trends  
3. Clean data: handle NaN, fill missing ratings  
4. Run SQL queries in PostgreSQL for deeper insights  
5. Build dashboards in Power BI for visualization  
6. Create report documenting findings  
7. Make PPT using Gamma for presentation  

📈 Dashboards  
Interactive Power BI dashboards highlight:  
- Customer purchase trends  
- Rating distributions  
- Behavior patterns across demographics  

📑 Results  
- Identified key purchase drivers  
- Found rating trends by product category  
- Built dashboards for quick decision‑making  
- Delivered a structured report and PPT for stakeholders  

▶️ How to Run  
1. Clone the repository  
2. Install requirements (`pandas`, `sqlalchemy`, `psycopg2`)  
3. Load dataset into Python notebook  
4. Connect PostgreSQL using SQLAlchemy  
5. Run analysis scripts  
6. Open Power BI file for dashboards  
7. Review report and PPT in `/docs` folder
